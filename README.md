# ntfy_speaker

**ntfy_speaker** - простой слушатель ntfy сервера под Windows. Отображает сообщения в панеле уведомлений Windows.

## Запуск
```shell
.\ntfy_speaker.exe -s "http://host.ru" -t "Topik" -p 8080 
```

## Функционал:

Отображение:
    - Тема
    - Сообшение
    - Кнопки: 
        - Прикрепленный файл
        - Прикрепленная ссылка
    - Нажатие на тело уведомления - откроет сайт с этим топиком
    - В зависимости от приоритета отображение Icon и задержка отображения:
        - 1-2 - уведомление скроется через 7 сек.
        - 3   - уведомление скроется через 25 сек.
        - 4-5 - уведомление ожидает действий пользователя.
