# ntfy_speaker

**ntfy_speaker** - простой слушатель ntfy сервера под Windows. Отображает сообщения панеле уведомлений Windows.

## Запуск
```shell
.\ntfy_speaker.exe -s "http://host.ru" -t "Topik" -p 8080 
```

## Функционал:
    Отображение:
        - Темы
        - Сообшения
        - События по нажатию на тело уведомления (переход на сервер в этот Топик или открытие переданной ссылки)
        - Отображение кнопки со ссылкой на прикрепленный файл или ссылку
        - В зависимости от приоритета отображение Icon (1-2 plus; 3 info; 4-5 warn)
